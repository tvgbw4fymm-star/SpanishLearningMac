# 西语喵 Mac 应用

原生 macOS 应用的工作目录。交互原型保存在 `Design/交互原型.html`，正式产品与技术规则保存在 `Design/产品与技术设计.md`。旧网页工具未被移动或修改，旧学习数据不迁移。

当前为 **0.9.9 精读交互修复预览**，保留了 0.6 的学习功能，并将总览页改为五张彩色学习卡、顶部搜索、待复习入口和下方 90 天热力图。侧边栏选中项只使用一层系统玻璃效果，窗口内容延伸到标题栏区域。可运行的预览包位于 `dist/西语学习-精读交互修复预览.zip`；解压后可双击 `.app` 检查。构建命令为 `scripts/build-design-preview.sh`，使用已安装的 Xcode SDK。旧版预览包继续保留，便于比较。

0.6 已实现的功能：已经编译通过的功能：原生侧边栏与听读写总览、从应用窗口导入音频并离线播放、在设置中将个人 OpenAI API 密钥保存到 macOS 钥匙串、在线逐段转写音频并保存进度、核对与拆并句子、逐句播放与听写、答案揭晓后的再听再写、AI 听辨提示、按多个积累点生成卡片草稿、按日期查看听写历史；卡片页面支持分类、全部来源回看、输入修改意见后立即显示 AI 修订结果，并由用户确认入库；相同语义与义项的卡片自动合并来源，同时保留既有复习进度；到期卡片采用 FSRS-6 的“重来 / 困难 / 良好 / 简单”评分排程；还有粘贴文章并按约 50 词切段、在左右分栏中进行对话式精读、获得不打断阅读节奏的简短回答、完成段落后把高价值问题整理为详细卡片草稿，并按文章查看精读历史；写作页可以从听力句子或阅读段落生成中文翻译题，也支持自由表达，提交后按意思、语法、用词和自然度四项评分，保存具体错误、修正版与同题历次版本，并生成待确认的写作纠错卡片；写作历史可按日期筛选。在“设置”中可以创建和恢复包含写作记录的本地备份。学习数据由应用写入当前用户的 `Application Support/SpanishLearningMac`，示例数据不进入正式资料。

在“设置 → 备份与恢复”创建 `.zip` 备份时，应用会打包学习记录和已导入的媒体文件，并逐文件校验。恢复前会展示音频、文章、阅读记录和卡片数量；检查通过后才会替换当前资料，恢复前的原资料会以可再次导入的 `.zip` 保存在同级的 `SpanishLearningMac Backups` 目录；如果原资料本身损坏，则保留原始目录副本。换电脑时，只需把 `.zip` 带到新电脑，在应用内选择“从备份恢复”。API 密钥不会进入备份，届时需要重新填写。应用还会在启动和离开前更新当天的自动备份，保留最近 14 份自动备份；手动备份和恢复前副本不会被自动清理。

听、读、写、卡片复习与本地迁移的第一版核心流程均已接入。当前转写和 AI 学习接口已经编译，并完成本机数据、切片、结构化响应模型与备份测试；由于没有使用你的个人 API 密钥，尚未执行真实在线转写、阅读问答、写作评分和卡片生成的端到端验收。在完成这次真实联网验收之前，仍视为开发预览。

运行 `scripts/build-app.sh` 会用本机 macOS 26.5 SDK 编译 SwiftUI 代码，并在 `dist/西语学习-开发预览.zip` 中保存经过临时目录签名与验证的 `.app`。之所以将开发预览封装为 zip，是因为此 SPM 目录的文件提供者会给直接放入其中的 `.app` 自动添加 Finder 扩展属性，干扰代码签名验证；解压后的应用已单独验证。`scripts/test-model.sh` 会验证文章切段、退出重开后的记录、听写尝试与原句的关联、语义重复卡片合并、FSRS 到期排程、阅读对话与卡片来源、写作多版本与纠错卡片来源、自动备份、含音频的备份迁移、损坏备份的拒绝，以及本机音频切片与带时间戳的响应解析。

构建脚本不读取旧网页工具的音频、数据或 API 密钥。后续用户密钥只在应用内设置，存入 macOS 钥匙串。

听力转写使用 macOS 本机西语语音识别；长音频会在本机切成短段处理。转写草稿会保留原音频时间轴；每段成功后立即保存，中断后可继续。转写文字可能有误，需在听写前核对。

卡片排程使用 open-spaced-repetition 的 `swift-fsrs`（MIT）所实现的 FSRS-6，代码和许可保存在工程及应用资源中。当前使用 90% 目标记忆率、1 分钟和 10 分钟学习步骤、10 分钟重学步骤；所有复习记录和下次到期时间都离线保存。

## AI 服务配置

文字 AI 统一使用 DeepSeek Responses API。在“设置 → AI 服务”填写 DeepSeek 密钥与模型；密钥只存于本机钥匙串，不进入学习资料或备份。学习解释、精读问答、写作题目与反馈、卡片修订都会使用 DeepSeek。旧 OpenAI 密钥不会被删除，但应用不再调用它。

音频转写使用 macOS 自带的西语本地语音识别，不调用 OpenAI，也不向 DeepSeek 上传音频。首次使用时需允许语音识别；系统须提供可用的西语本机识别资源。识别结果按短音频分段保存，用户仍需核对文字与时间。用于分发的应用构建已加入 `NSSpeechRecognitionUsageDescription`；如果直接从缺少该权限说明的 Xcode 运行配置启动，应用会显示配置错误以避免系统崩溃。
