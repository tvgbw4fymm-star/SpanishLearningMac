# 西语学习 Mac 应用：正式设计基线

状态：开发基线，2026-09-21。交互参考见 `交互原型.html`。正式界面使用 SwiftUI / AppKit 原生控件；原型中的示例数据和模拟 AI 结果不进入正式数据。

## 学习对象与来源

每份材料有稳定 ID、标题、类型、导入时间和原始内容。音频导入后复制进应用管理的媒体目录；文章保留原文。切句、切段使用独立 ID 和顺序号，保存其原始材料 ID 与时间范围或文本位置。人工修改切片只更新当前版本，不改变练习记录引用的稳定 ID；需要拆分或合并时保存来源映射，避免历史记录悬空。

听写记录保存句子 ID、提交日期、每一轮原文输入、是否已看答案、解释与积累点。历史按本地日期归类，可以复听单句或整天。阅读记录保存文章 ID、段落 ID、完成日期、初评难度、提问、简短答复和完成后备注；历史按文章归类。写作练习保存来源材料、中文题目、练习 ID 与每次提交的版本、日期、AI 反馈和四类分数；同一练习的历次版本显示在一个块内，可按提交日期筛选。

## 卡片与复习

卡片先以草稿存在。用户可以写修改意见，应用调用 AI 生成修订稿并展示完整新内容；只有用户确认后才入库。分类为词汇、语法、表达、知识和写作纠错。卡片保存所有来源引用，重复词汇或相似问题提示合并；不同义项、不同用法可分开保留。合并保留既有复习历史和原始提问。卡片复习采用 FSRS，保存每次“重来、困难、良好、简单”评分及下次到期时间；自由回看不改变排程。

## AI 与离线边界

联网能力包括音频转写、听力难点解释、精读问答、写作反馈、卡片草稿与修订。应用在设置页读取用户输入的 OpenAI API 密钥并保存到 macOS 钥匙串，不写入学习数据库或备份。已有材料的播放、听写、阅读、写作记录查看和到期卡片复习在离线时仍可用。所有 AI 结果标注生成状态；请求失败时保留用户草稿并允许重试。长音频按服务限制分片上传，保留每段与原音频时间轴的映射；转写结果须可人工核对。

## 本地数据与迁移

结构化数据放在应用的 Application Support 目录，媒体文件由应用复制管理。写入采用原子保存或事务，记录格式带版本号。备份包包括数据库、音频、文章、卡片、评分历史和来源关联，并记录校验信息；恢复前展示包版本与内容摘要，成功校验后再替换当前资料。API 密钥不在备份包中，换机后在应用内重填。自动备份和手动备份都允许选择本地目标，验收时须在全新空白资料目录完成恢复测试。

## 原生界面

导航为总览、听、听写历史、读、阅读历史、写、写作历史、卡片、设置。总览展示最近 90 天听读写合并热力图，下面显示细分数据。密集数据不在小方格里强放日期数字；日期与各项贡献由悬停或选中显示。玻璃材质用于侧边栏和工具栏，正文、播放器、输入区保持高对比与稳定排版。所有主要操作支持键盘与 VoiceOver 标签。

## 开发顺序与验收

先完成原生窗口、模型、持久保存、音频与文章导入；再完成听读写离线流程和历史；接入 AI 和可核对的结果；完成草稿修订、去重与 FSRS；最后完成备份恢复、视觉细化、错误处理和可双击运行的 `.app`。每个阶段都以真实退出重开后的记录完整性为验收条件。正式版不得使用原型中的演示结果冒充 AI 评价。
